# Гистология · отдельный тренажёр препаратов

Самостоятельная статическая платформа для тренировки гистологических препаратов по микрофотографиям. Сделана в этом репозитории как эксперимент: чтобы на живом примере сравнить **отдельную платформу** и гипотетический **раздел внутри основного тренажёра** [`DISKLAY/disklay`](https://github.com/DISKLAY/disklay). Основной репозиторий не изменяется.

## Запуск

Приложение полностью статическое, сборка не нужна:

```bash
# вариант 1: просто открыть index.html в браузере
# вариант 2: локальный сервер
python3 -m http.server 8080 --bind 0.0.0.0
# затем http://localhost:8080
```

Либо `npm start` (тот же статический сервер). Внешних запросов, аккаунтов и базы данных нет — прогресс хранится в `localStorage` браузера.

## Что умеет

- **Тренировка** — показать препарат без подписей; ответить выбором из 4 вариантов или ввести название вручную.
- **Подсказки** — раздел, окраска, номер препарата и замаскированное название.
- **Разбор** — верный ответ, характеристика, номер, окраска и исходный слайд с подписями (кнопка «Показать подписанный снимок»).
- **Атлас** — все препараты по 12 разделам с поиском по названию, номеру и окраске; просмотр чистых и подписанных снимков, увеличение по клику.
- **Работа над ошибками**, **избранное**, **статистика** по разделам и сессиям.
- **Сравнение** — разбор «отдельная платформа против встроенного раздела» прямо в интерфейсе (`#/compare`) и подробно в [`docs/comparison.md`](docs/comparison.md).
- Светлая/тёмная темы, адаптивная вёрстка, горячие клавиши: `1`–`4` — ответ, `Enter` — далее, `H` — подсказка, `F` — избранное, `Z` — увеличить.

### Подписи

Там, где в PDF есть версия фотографии без подписей, используется **она напрямую** — изображение извлекается как XObject, без рендера векторного текста.

Если чистой версии нет (подписи «запечены» в растр), кадр обрабатывается `scripts/build_assets.py`:

1. обрезаются верхний заголовок и белые поля слайда;
2. нейтрально-тёмный текст, рамки, стрелки и светлые выноски объединяются в маску;
3. маска заливается **непрозрачно** мягким тоном ткани (размытый кадр + медианный цвет препарата);
4. большие светлые участки самой ткани не затрагиваются (ограничение по площади компоненты);
5. кадры, где после обработки осталось слишком много белого, отбраковываются.

Обработанные карточки помечены `masked: true` и бейджем «подписи удалены» в интерфейсе.

## Структура

```
index.html                  разметка и подключение скриптов

js/app.js                   логика, роутинг, статистика, localStorage

tests/*.test.js             проверки целостности данных
```

## Пересборка ассетов

Исходные PDF в репозиторий не включены. Если нужно пересобрать:

```bash
python3 -m pip install --break-system-packages PyMuPDF pillow numpy opencv-python-headless
python3 scripts/build_assets.py --pdf-dir /path/to/pdfs --out .
```

Скрипт читает PDF `Гистология_0113-0220-сжатый.pdf`, `Гистология_0221-0330-сжатый.pdf`, `Гистология_0331-0426-сжатый.pdf`, склеивает нарезанные растровые полосы, выбирает менее подписанный кадр из пар, убирает дубликаты по dHash и записывает манифест и JPEG. Диапазоны слайдов, названия, окраски и подсказки заданы константой `GROUPS` в скрипте — это единственное место, которое нужно править при добавлении новых PDF.

## Ограничения

Названия, номера и окраски перенесены из предоставленных материалов и не проходили отдельной медицинской сверки. Часть снимков — схемы или кадры с авторскими подписями; после автоматической обработки они помечены соответствующим бейджем. Тренажёр не заменяет работу с атласом и преподавателем.

Архитектурно проект ориентируется на `DISKLAY/disklay` (статический офлайн-формат, обычные `<script>`-банки, светлая/тёмная темы, карточки, работа над ошибками), но намеренно живёт отдельно: так проще оценить удобство самостоятельной платформы по сравнению со встроенным режимом.
