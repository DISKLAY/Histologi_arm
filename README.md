# Гистология · отдельный тренажёр препаратов

Самостоятельная статическая платформа для тренировки гистологических препаратов по микрофотографиям. Сделана в этом репозитории как эксперимент: чтобы на живом примере сравнить **отдельную платформу** и гипотетический **раздел внутри основного тренажёра** [`DISKLAY/disklay`](https://github.com/DISKLAY/disklay). Основной репозиторий не изменяется.

## Запуск

Приложение полностью статическое, сборка не нужна:

```bash
# вариант 1: просто открыть index.html в браузере
# вариант 2: локальный сервер
python3 -m http.server 8080 --bind 0.0.0.0
# затем http://localhost:8080
```

Либо `npm start` (тот же статический сервер). Внешних запросов, аккаунтов и базы данных нет — прогресс хранится в `localStorage` браузера.

## Что умеет

- **Тренировка** — показать препарат без подписей; ответить выбором из 4 вариантов или ввести название вручную.
- **Подсказки** — раздел и окраска, а также описание того, что видно на срезе. Название препарата и его номер в подсказку не попадают: в режиме выбора буквенная маска сразу давала ответ, поэтому там показывается описание структуры, а маска первых букв осталась только в режиме ввода.
- **Разбор** — верный ответ, характеристика, номер, окраска и исходный слайд с подписями (кнопка «Показать подписанный снимок»).
- **Атлас** — все препараты по 12 разделам с поиском по названию, номеру и окраске; просмотр чистых и подписанных снимков, увеличение по клику.
- **Работа над ошибками**, **избранное**, **статистика** по разделам и сессиям.
- **Сравнение** — разбор «отдельная платформа против встроенного раздела» прямо в интерфейсе (`#/compare`) и подробно в [`docs/comparison.md`](docs/comparison.md).
- Светлая/тёмная темы, адаптивная вёрстка, горячие клавиши: `1`–`4` — ответ, `Enter` — далее, `H` — подсказка, `F` — избранное, `Z` — увеличить.

### Подписи

Там, где в PDF есть версия фотографии без подписей, используется **она напрямую** — изображение извлекается как XObject, без рендера векторного текста.

Если чистой версии нет (подписи «запечены» в растр), кадр обрабатывается `scripts/build_assets.py`. Маскируются **строго буквы**: стрелки, выноски, рамки и ткань остаются как есть.

1. обрезаются верхний заголовок и белые поля слайда;
2. OCR (RapidOCR, несколько масштабов) находит строки подписей, включая подписи в несколько строк;
3. каждая строка расширяется до реальных границ букв: OCR обрезает края, и по его прямоугольнику подпись стирать нельзя;
4. внутри строки ищутся «чернила» — пиксели, которые заметно темнее локального фона и почти не окрашены (ткань препарата всегда окрашена, буквы — чёрные);
5. если строка стоит на ровной светлой плашке или выноске, найденные «чернила» заливаются цветом плашки — фон не меняется, поэтому швов и белых прямоугольников не остаётся;
6. если строка нанесена прямо на ткань, её пиксели восстанавливаются inpaint'ом по окружению;
7. длинные тонкие линии (стрелки, обводки выносок), найденные преобразованием Хафа, всегда возвращаются из оригинала и в маску не попадают;
8. проход повторяется, чтобы снять остатки антиалиасинга и обрезанные OCR хвосты слов.

В результате стираются именно буквы: выноска сохраняет свою форму и обводку, стрелка остаётся на месте, ткань препарата не меняется.

Для маскировки нужны `rapidocr-onnxruntime` и `opencv-python-headless` (`pip install rapidocr-onnxruntime opencv-python-headless`). Без OCR сборка останавливается с подсказкой — подписи не маскируются вслепую.

Обработанные карточки помечены `masked: true` и бейджем «подписи удалены» в интерфейсе.

## Структура

```
index.html                  разметка и подключение скриптов
css/styles.css              темы, компоненты, адаптив

js/data/preparations.js     сгенерированный манифест препаратов

assets/reveal/*.jpg         исходные подписанные слайды

scripts/build_assets.py     генератор манифеста и изображений из PDF
tests/*.test.js             проверки целостности данных
```

## Пересборка ассетов

Исходные PDF в репозиторий не включены. Если нужно пересобрать:

```bash
python3 -m pip install --break-system-packages PyMuPDF pillow numpy opencv-python-headless
python3 scripts/build_assets.py --pdf-dir /path/to/pdfs --out .
```

Скрипт читает PDF `Гистология_0113-0220-сжатый.pdf`, `Гистология_0221-0330-сжатый.pdf`, `Гистология_0331-0426-сжатый.pdf`, склеивает нарезанные растровые полосы, выбирает менее подписанный кадр из пар, убирает дубликаты по dHash и записывает манифест и JPEG. Описания препаратов берутся из прозы PDF: сначала ищется текстовая страница группы, затем абзацы на страницах со слайдами. Для препаратов, у которых в PDF есть только снимки с подписями-стрелками, тексты заданы вручную в `HINTS_MANUAL`. Диапазоны слайдов, названия, окраски и подсказки заданы константой `GROUPS` — это единственное место, которое нужно править при добавлении новых PDF. Обновить только описания, не пересобирая ассеты: `python3 scripts/build_assets.py --only-hints`.

## Ограничения

Названия, номера и окраски перенесены из предоставленных материалов и не проходили отдельной медицинской сверки. Часть снимков — схемы или кадры с авторскими подписями; после автоматической обработки они помечены соответствующим бейджем. Тренажёр не заменяет работу с атласом и преподавателем.

Архитектурно проект ориентируется на `DISKLAY/disklay` (статический офлайн-формат, обычные `<script>`-банки, светлая/тёмная темы, карточки, работа над ошибками), но намеренно живёт отдельно: так проще оценить удобство самостоятельной платформы по сравнению со встроенным режимом.
